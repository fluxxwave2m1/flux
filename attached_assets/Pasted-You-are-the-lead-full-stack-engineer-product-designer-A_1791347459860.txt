8. AI WORKFLOW GENERATOR
==================================================

THIS IS THE MOST IMPORTANT FEATURE.

The AI must interpret natural-language instructions and convert them into a structured workflow.

Do NOT allow the AI to directly generate executable arbitrary code.

Instead force the AI to output a strict structured JSON schema.

Example:

{
  "name": "Customer Onboarding",
  "description": "Automates customer onboarding",
  "trigger": {
    "type": "customer.created",
    "label": "New Customer Registered"
  },
  "nodes": [
    {
      "id": "node_1",
      "type": "trigger",
      "label": "New Customer Registered"
    },
    {
      "id": "node_2",
      "type": "action",
      "actionType": "send_email",
      "label": "Send Welcome Email"
    },
    {
      "id": "node_3",
      "type": "action",
      "actionType": "create_record",
      "label": "Create CRM Record"
    },
    {
      "id": "node_4",
      "type": "action",
      "actionType": "notification",
      "label": "Notify Sales Team"
    }
  ],
  "edges": [
    ["node_1", "node_2"],
    ["node_2", "node_3"],
    ["node_3", "node_4"]
  ]
}

The AI response must be validated before being accepted.

If invalid:

- attempt structured repair
- otherwise show a useful error
- never crash the application
